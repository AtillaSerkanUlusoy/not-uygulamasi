git branch: dallari listeler olusturur veya siler
git init: bulunan klasore yeni bir git deposu olusturur

git push: bilgisayardaki kayitli degisiklikleri uzak sunucuya gonderir

git commit: hazirlik asamasindaki degisiklikleri ne yapildigina dair kisa bir mesajla birlikte kalici olarak kaydeter
git clone: Uzak sunucudaki mevcut bir projeyi bilgisayariniza indirir.
